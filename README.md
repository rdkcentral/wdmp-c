# wdmp-c

C implementation of the WebPA Data Model Parser

## Origin

This repository is based on the original
[wdmp-c](https://github.com/xmidt-org/wdmp-c) source code
maintained under the xmidt-org organization. The code was copied into the
rdkcentral organization, where ongoing maintenance and development now take place.

- Original project: https://github.com/xmidt-org/wdmp-c
- Current repository: https://github.com/rdkcentral/wdmp-c

# Building and Testing Instructions

```
mkdir build
cd build
cmake ..
make
make test
```
